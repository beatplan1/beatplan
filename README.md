## What it is

Beatplan is the complete source code of a field sales system that has run a real distributor's field team every working day since November 2025. It's built for companies whose reps visit dealers and customers on a plan, collect payments, take orders and drive company cars.

| | |
|---|---|
| **Day plans** | Each rep's visits for the day, set by their team lead |
| **Verified visits** | Time-stamped, GPS-checked, with photos and notes |
| **Collections** | Payments recorded against monthly and period targets, validated by Accounts |
| **Dealer orders** | From the rep's phone through review, dispatch and payment |
| **Company cars** | Odometer readings, inspections and the rep's expense sheet |
| **Director view** | Every region and rep against target, with alerts for slipping dealers |
| **Roles** | Field rep, team lead, admin, director, accounts, logistics |

## Tech stack

- **App:** Expo SDK 58 / React Native for iPhone, Android and the web, with offline queueing for field use
- **Backend:** Supabase (Postgres) with 64 tables, 132 server functions and 163 row-level security rules
- **Tests:** 33 automated security tests
- **Size:** about 55,000 lines of app code across 86 screens
- **Configuration:** company name, currency, regions, role and activity names and a second language in one settings file

## Set it up with your own AI assistant

The download includes a setup guide written for AI coding assistants. Open the folder in **Claude Code** (part of the Claude app) or **Codex** (part of ChatGPT) and say:

```
Set up Beatplan for my company, Northwind Seeds. We sell in euros
in two regions, North and South. My email is maria@northwindseeds.com.
```

It brands the app, creates your Supabase database, runs the security tests and adds you as the first admin, asking before each change. You'll need free Supabase and Expo accounts, and your own App Store and Google Play accounts to publish the phone apps under your company name.
